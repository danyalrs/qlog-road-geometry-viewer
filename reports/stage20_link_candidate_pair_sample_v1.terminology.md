## Finding

The file `reports/stage20_link_ground_truth_sample.json` is **misnamed**. It is **not** manually reviewed ground truth and was **not** validated against qlog video.

### How labels were produced

Generated by `reports/stage20_design_investigation_runner.js` on 2026-07-28:

1. Enumerate consecutive observation pairs within Stage 19 multi-observation partition units (5,010 pairs dataset-wide; 576 pairs in target segments).
2. Apply deterministic **rule-derived** classifier `classifyPair()` — same boundary checks as Rev 37 geometry gates plus gap/session/chunk/pass/section heuristics.
3. **No human reviewer** assigned labels.
4. **`videoEvidenceAvailable: false`** at generation time; `requiresManualReviewCount: 0` because rule classifier set `uncertainty: low` for gap and session-boundary rejections.
